# Part 1 Vue + FastAPI CSV Search Prompt

Build only the Part 1 portion of a local hotel and available-stay search. Use Vue/Vite in `frontend/`, Python FastAPI in `backend/`, and the instructor-supplied `data/hotels.csv` plus `data/trips.csv`. FastAPI must read both files, join them using `hotel_id`, and return hotel-name matches with available stays as JSON. Vue must provide a hotel-name input, Search button, labeled plain table, and clear no-results message. Do not hard-code result data in Vue. Do not add SQLite, CRUD, booking, authentication, payment, or external APIs. Document expected and observed outcomes for one successful search and one no-results search.
